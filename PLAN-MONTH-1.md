# План на первый месяц (1–31 октября 2026)

Цель месяца — сквозной срез: студент входит, идёт по первому этажу в кабинет, открывает тест, который создал преподаватель, проходит его, и оценка видна обоим.

Общее описание проекта: [PROJECT.md](PROJECT.md).

## Неделя 1 (1–7 октября)

**Все вместе, в первый день**
- Создать репозиторий на GitHub, добавить всех троих.
- Создать проект Next.js с React Three Fiber и проект в Supabase, выложить пустую страницу на Vercel.
- Договориться: каждый работает в своей ветке, вливание через пул-реквест.

**Моделирование**
- Сфотографировать схемы всех четырёх этажей.
- Описать первый этаж в JSON: стены, двери, номера и названия кабинетов.
- Поставить Blender и подключить к нему ИИ через MCP, сделать пробный предмет (парта).

**Бэкенд и Academo**
- Сходить в IT-отдел с пятью вопросами из PROJECT.md.
- Таблицы в базе: пользователи, роли, группы, дисциплины, кабинеты.
- Вход по почте с тремя ролями: студент, преподаватель, админ.

**Панели**
- Каркас сайта: страница входа, пустая панель студента, пустая панель преподавателя.
- Макет экрана создания теста (на бумаге или в коде, без сохранения).

## Неделя 2 (8–14 октября)

**Моделирование**
- Код, который строит стены, пол и двери первого этажа из JSON.
- Персонаж-заглушка ходит по этажу и не проходит сквозь стены.

**Бэкенд и Academo**
- Таблицы: задания, вопросы теста, попытки, оценки.
- Каркас адаптера Academo, работающий на наших данных.
- Записать ответы IT-отдела в PROJECT.md.

**Панели**
- Преподаватель создаёт тест: название, дисциплина, вопросы с вариантами, правильный ответ, дедлайн. Тест сохраняется в базу.

**Контрольная точка 14 октября:** смотрим первый этаж, построенный из JSON. Если выглядит приемлемо, продолжаем так же. Если нет, решаем, что менять.

## Неделя 3 (15–21 октября)

**Моделирование**
- Холл в Blender по фотографиям, вставить в сцену.
- Камера: третье лицо, приближение до первого.
- Номера кабинетов над дверями.

**Бэкенд и Academo**
- Автопроверка теста и запись оценки.
- Правила доступа: студент видит задания только своих групп, преподаватель только свои дисциплины.

**Панели**
- Студент видит список заданий, проходит тест, видит результат.
- Преподаватель видит, кто прошёл и с какой оценкой.

## Неделя 4 (22–31 октября)

**Моделирование**
- Один кабинет с мебелью (парты, стулья, доска).
- Вход в кабинет открывает задания его дисциплины.

**Бэкенд и Academo**
- Привязка дисциплины к кабинету.
- Тестовые данные: одна группа, один преподаватель, одна дисциплина.

**Панели**
- Кнопка «телепорт в кабинет» из списка заданий.
- Окно задания поверх 3D-сцены.

**Все вместе**
- Пройти всю цепочку с трёх разных учётных записей, записать найденные ошибки.
- Показать научному руководителю.

## Итог месяца

31 октября честно отвечаем на один вопрос: готов ли срез. Если да, идём по этапам из PROJECT.md. Если нет, в тот же день сокращаем объём по списку «что режем».
