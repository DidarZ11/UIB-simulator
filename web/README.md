# UIB Simulator — веб-приложение

Next.js + React Three Fiber. Описание проекта и план лежат уровнем выше: `../PROJECT.md`, `../PLAN-MONTH-1.md`.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

Управление: WASD или стрелки — ходить, клик по экрану — камера мышью (Esc отпускает), колесо — приближение до вида от первого лица.

## Как устроен этаж

Этаж целиком описан в `src/data/floors/floor1.json`. Код в `src/game/` строит по нему стены, панели, окна, двери и столкновения. Чтобы поменять планировку, правится только JSON.

Координаты в метрах: `x` растёт на восток, `y` на север. Точка `[0, 0]` — юго-западный угол холла (угол у баннеров, справа от окна, если стоять лицом к выходу).

| Раздел | Что описывает |
|---|---|
| `walls` | Стена от `from` до `to`, только вдоль осей. `openings` — проёмы: `window`, `door` (закрытая дверь) или `passage` (открытый проход). `at` — расстояние от `from` до начала проёма. `style: "glass"` — стеклянная перегородка в коричневой раме. |
| `pillars` | Колонны: центр `at` и размер `size`. |
| `floors` | Прямоугольники пола и потолка `[x, y, ширина, глубина]`. |
| `accentTiles` | Светлые плитки на полу. |
| `murals` | Рисунки на стенах. Сами рисунки рисуются в `src/game/textures.ts`. |
| `signs` | Таблички с текстом. |
| `props` | Баннеры, зеркало, телевизор, фоторамка. |
| `zones` | Названия мест, которые показываются в левом верхнем углу. |
| `spawn` | Где появляется игрок. |

## Проверка места по фотографии

Адрес `http://localhost:3000/?at=6,7,180` ставит игрока в точку `x=6, y=7` лицом на юг. Третье число — поворот в градусах: 0 — север, 90 — запад, 180 — юг, -90 — восток.

## Что сейчас приблизительно

Все размеры сняты с фотографий на глаз, рулеткой никто не мерил. Западный проход (двери и спортзал) и восточный коридор дальше первой двери расставлены условно: фотографий этих мест пока нет.
